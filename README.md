# שדכן אבדות – מערכת טלפונית בימות המשיח

מערכת טלפונית לאיתור אבדות ומציאות באוטובוסים. המערכת משדכת בין מי שאיבד למי שמצא. באוטובוסים השידוך נעשה לפי **מספר הרכב עצמו**, בעזרת המאגר הציבורי Open Bus של "הסדנא לידע ציבורי".

## תפריט ראשי
| מקש | פעולה |
|---|---|
| 1 | איבדתי חפץ באוטובוס |
| 2 | מצאתי חפץ באוטובוס |
| 3 | השידוכים שלי |
| 4 | הדיווחים שלי (מיקום האוטובוס כעת, מחיקת דיווח) |
| 0 | יציאה |

## מהלך השיחה (איבדתי / מצאתי)
1. **תאריך:** היום מקישים 0 וסולמית. לתאריך אחר מקישים 6 ספרות: יום, חודש, שנה (למשל 120526).
2. **מספר תחנה:** מי שזוכר מקיש 1 ואחר כך את המספר שעל שלט התחנה. מי שלא זוכר מקיש 2.
3. **מספר קו:**
   - **עם תחנה:** המערכת מזהה לבד את החברה ואת הכיוון.
   - **בלי תחנה:** בוחרים עיר וכיוון מתפריט.
4. **שעת היציאה הרשמית** של הקו מתחנת המוצא, בארבע ספרות. המערכת מזהה את האוטובוס ומקריאה את **מספר הרישוי**. אם אין נסיעה בדיוק בשעה הזו, היא מציעה את הנסיעה הקרובה.
5. מקישים 1 לשמירה ומקליטים תיאור. המערכת שומרת גם את האוטובוסים של **הנסיעה הקודמת והבאה**, למקרה שהמתקשר טעה בשעה.
6. **צינתוק (רק למאבד):** המאבד בוחר כיוון, או "כל מסלול חדש". כשהאוטובוס מתחיל מסלול חדש הוא מקבל צינתוק, מתקשר חזרה ושומע למשל: *"התחיל כעת קו 3 של השעה 9 לכיוון..., שידר לפני 2 דקות"*.

## השידוך
- **אותו רכב** אצל מאבד ומוצא: **שידוך ודאי**. שניהם מקבלים צינתוק ושומעים את הטלפון ואת ההקלטה של הצד השני.
- **הרכב של הנסיעה הקודמת או הבאה:** **הצעה** בלבד. המאבד מאשר "זה שלי", ואז הטלפונים נחשפים.

## הגדרת השלוחה בימות המשיח
```
type=api
api_link=https://YOUR-APP.onrender.com/ivr
```
ההקלטות נשמרות בשלוחה 9. צריך ליצור אותה מראש.

## משתני סביבה
| משתנה | תפקיד |
|---|---|
| `ADMIN_KEY` | סיסמה לדף הניהול `/admin?key=...` |
| `YEMOT_TOKEN` | `מספר_מערכת:סיסמה` לשליחת צינתוקים. בלעדיו הצינתוקים רק נרשמים בלוג |
| `RECORD_FOLDER` | שלוחה לשמירת ההקלטות (ברירת מחדל `/9`) |
| `DB_PATH` | קובץ מסד הנתונים. ב-Render בתשלום מפנים אותו לדיסק קבוע |
| `EXPIRE_DAYS` | מספר הימים שדיווח נשאר פעיל (ברירת מחדל 45) |

את רשימות הערים והקטגוריות עורכים ב-`src/config.js`.
