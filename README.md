# שדכן אבדות – מערכת טלפונית בימות המשיח

מערכת טלפונית לאיתור אבדות ומציאות. המערכת משדכת בין מי שאיבד למי שמצא. באוטובוסים השידוך נעשה לפי **מספר הרכב עצמו**, בעזרת המאגר הציבורי Open Bus של "הסדנא לידע ציבורי".

## תפריט ראשי
| מקש | פעולה |
|---|---|
| 1 | איבדתי חפץ |
| 2 | מצאתי חפץ |
| 3 | השידוכים שלי |
| 4 | הדיווחים שלי (מיקום האוטובוס כעת, מחיקת דיווח) |
| 0 | יציאה |

## איך עובד השידוך
- **באוטובוס:** המתקשר מקיש קו, עיר, כיוון ושעה, והמערכת מאתרת את מספרי הרכבים שנסעו בקו באותה שעה. כשמאבד ומוצא דיווחו על אותו רכב, נוצר **שידוך ודאי**: שניהם מקבלים צינתוק, ושומעים את הטלפון ואת ההקלטה של הצד השני.
- **ברחוב או במקום אחר:** השידוך לפי קטגוריה ועיר. המערכת משמיעה למאבד **הצעה**, בלי לחשוף את הטלפון של המוצא. כשהמאבד מאשר "זה שלי", המוצא מקבל צינתוק ושני הצדדים מקבלים את מספרי הטלפון.
- **"האוטובוס בעיר שלך":** מאבד יכול לבחור עיר. כל 3 דקות המערכת בודקת איפה הרכב נמצא. כשהרכב מתחיל נסיעה שעוברת בעיר שבחר, המאבד מקבל צינתוק, ובשיחה החוזרת הוא שומע באיזה קו הרכב נוסע.

## הגדרת השלוחה בימות המשיח
```
type=api
api_link=https://YOUR-APP.onrender.com/ivr
```
ההקלטות נשמרות בשלוחה 9. צריך ליצור אותה מראש.

## משתני סביבה
| משתנה | תפקיד |
|---|---|
| `ADMIN_KEY` | סיסמה לדף הניהול `/admin?key=...` |
| `YEMOT_TOKEN` | `מספר_מערכת:סיסמה` לשליחת צינתוקים. בלעדיו הצינתוקים רק נרשמים בלוג |
| `RECORD_FOLDER` | שלוחה לשמירת ההקלטות (ברירת מחדל `/9`) |
| `DB_PATH` | קובץ מסד הנתונים. ב-Render בתשלום מפנים אותו לדיסק קבוע |
| `EXPIRE_DAYS` | מספר הימים שדיווח נשאר פעיל (ברירת מחדל 45) |

את רשימות הערים והקטגוריות עורכים ב-`src/config.js`.
